# Kranti Cabs - Flutter Projects

This repository contains the Flutter mobile applications for **Kranti Cabs**:

- **`Kranti_cabs/`**: Rider / Customer mobile application (booking, ride tracking, payments, KYC).
- **`kranticabs_driver/`**: Driver partner mobile application (onboarding, real-time requests, earnings, demand map, trip navigation).

## Getting Started

Each project is a standalone Flutter project. To run either application:

### Customer App
```bash
cd Kranti_cabs
flutter pub get
flutter run
```

### Driver App
```bash
cd kranticabs_driver
flutter pub get
flutter run
```
